What each tool does.

Minimap

Markdown roadmaps and shared spec review with agents.

  • Features, priorities, and scope stay in the repo where agents can work with them.
  • Review specs together with agents through comments and proposed edits.

Agent Workflow

A risk-aware workflow with a reviewable record and CI checks for coding-agent tasks.

  • Each task leaves a Work Record: a file showing what the agent planned, changed, and checked.
  • CI compares the agent's reported risk with the actual code changes.

Pallium

Agent communication layer and searchable session history across coding tools.

  • Agents working in Claude Code, Codex, and OpenCode can use Pallium Relay to ask questions, respond, and share findings.
  • Decisions and context remain searchable across earlier sessions and tools.

The work should outlast the chat.

Plans, decisions, checks, and earlier messages remain available to the next session or reviewer.

A closer look at each tool.

Minimap

  • Roadmaps from MarkdownUse repo files to manage features, priorities, and scope. Minimap turns them into a board that developers and agents can update.
  • Specs reviewed togetherDiscuss a spec with agents beside the text. Review comments and proposed edits before applying them.

Agent Workflow

  • Work Record beside the codeThe task's scope, decisions, risk, and checks stay in one file for the next session or reviewer.
  • CI enforces the workflowIt compares the Work Record with the actual changes, catching skipped steps, understated risk, and architecture violations.
