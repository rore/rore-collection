# Contributing to the collection

This repository contains the collection overview, installation guide, static site,
and collection-level proposals. Tool implementations and tool-specific roadmaps
belong in their respective repositories.

## Content

- Keep public copy concise, concrete, and consistent across README.md, INSTALL.md,
  and docs/index.html. Avoid repeated explanations and unsupported claims.
- Distinguish shipped capabilities from proposals. Each tool works independently.
- Link to each tool's maintained installation instructions rather than duplicating
  commands or runtime support matrices.
- Keep screenshots limited to synthetic examples or intentionally public data.
  Inspect visible text, embedded image data, and metadata before committing.
- Do not commit private conversations, memory exports, credentials, local paths,
  workplace material, or personal session-specific instructions. Use ignored
  AGENTS.local.md or .local/ for machine-specific notes.

## Changes and publication

- Keep the site static; prefer existing HTML/CSS and avoid unnecessary dependencies.
- Preserve unrelated edits. Validate links and affected behavior; check layout at
  desktop and mobile widths after visual changes.
- GitHub Pages serves docs/ from main. Changes pushed there are public after deployment.
- The public README is for visitors. Keep contributor procedures here and proposed
  feature details in their own files.
